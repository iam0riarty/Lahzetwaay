# 🌙 لحظة وعي — دليل التثبيت الكامل

## المتطلبات
- Node.js 18+
- حساب Supabase (مجاني)
- حساب Vercel (مجاني للنشر)

---

## الخطوة ١ — إعداد Supabase

١. اذهب إلى https://supabase.com وأنشئ مشروع جديد
٢. من القائمة الجانبية → **SQL Editor**
٣. انسخ كل الـ SQL الموجود في ملف `src/lib/supabase.js` (بين التعليقات) وشغّله
٤. من **Settings → API** انسخ:
   - `Project URL`
   - `anon public key`

---

## الخطوة ٢ — إعداد المشروع محلياً

```bash
# تثبيت المكتبات
npm install

# أنشئ ملف البيئة
cp .env.example .env.local

# عدّل .env.local بالبيانات من Supabase
REACT_APP_SUPABASE_URL=https://xxxx.supabase.co
REACT_APP_SUPABASE_ANON_KEY=eyJ...

# شغّل محلياً
npm start
```

---

## الخطوة ٣ — النشر على Vercel

```bash
npm install -g vercel
vercel

# أضف متغيرات البيئة في Vercel Dashboard
# Settings → Environment Variables
```

## هيكل الصلاحيات

| النافذة | من يدخلها | الكود |
|---|---|---|
| الأعمال اليومية | كل الأعضاء | بدون كود — لكن لازم تسجيل |

| الأدمن | أنت فقط | كود `admin` |
